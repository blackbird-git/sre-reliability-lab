# SRE Reliability Lab

This home lab develops practical skills in deploying, monitoring,
and troubleshooting a containerized HTTP application.
Planned exercises cover infrastructure automation, CI/CD,
and recovery from deliberately introduced failures.

## Planned Technologies

- Git and GitHub
- Python
- Docker
- Kubernetes with kind
- Prometheus
- Grafana
- GitHub Actions
- Terraform and AWS

This is a learning environment, not a production deployment.
